# ProxPilot Configuration Guide

This document describes all configuration options for ProxPilot 1.5.2.

# Environment

Copy the example configuration:

```bash
cp .env.example .env
```

Only `.env.example` should be committed to Git.

---

# Proxmox API

## PVE_ENDPOINTS

Comma-separated list of Proxmox API endpoints.

Example:

```dotenv
PVE_ENDPOINTS=https://pve1.example.com:8006,https://pve2.example.com:8006
```

## PVE_TOKEN_ID

Example:

```dotenv
PVE_TOKEN_ID=dashboard@pve!dashboard
```

## PVE_TOKEN_SECRET

The API token secret generated by Proxmox.

## PVE_VERIFY_SSL

```dotenv
PVE_VERIFY_SSL=true
```

Use `false` only for trusted lab environments with self-signed certificates.

---

# SSH

## PVE_SSH_USER

Default:

```dotenv
PVE_SSH_USER=root
```

## PVE_SSH_KEY

```dotenv
PVE_SSH_KEY=/app/ssh/id_ed25519
```

## PVE_SSH_PORT

```dotenv
PVE_SSH_PORT=22
```

## PVE_NODE_HOSTS

Maps Proxmox node names to SSH/API addresses.

Example:

```dotenv
PVE_NODE_HOSTS=pve=192.168.123.10,pve2=192.168.123.11
```

# Authentication

## PROXPILOT_AUTH_ENABLED

Enable or disable authentication.

## PROXPILOT_AUTH_USERNAME

Bootstrap administrator (used only during first initialization).

## PROXPILOT_AUTH_PASSWORD

Bootstrap password (used only during first initialization).

## PROXPILOT_SESSION_SECRET

Generate a strong random value.

## PROXPILOT_COOKIE_SECURE

Enable when using HTTPS.

## PROXPILOT_SESSION_MAX_AGE

Session lifetime in seconds.

# LDAP

LDAP configuration is managed through the web interface.

Supported features:

- Active Directory
- OpenLDAP
- LDAPS
- StartTLS
- Bind account
- Group mapping
- Default role
- Administrator mapping
- Operator mapping
- Viewer mapping
- Connection test before saving

---

# Audit Log

Audit retention is configured from the Settings page.

Features:

- Configurable retention period
- Automatic cleanup
- CSV export
- JSON export
- Multi-filter support
- Context-aware filter values

---

# Database

The SQLite database is created automatically:

```text
./data/proxpilot.db
```

---

# Reverse Proxy

Recommended:

- HTTPS
- Secure cookies
- WebSocket support
- Forward X-Forwarded-For / X-Real-IP headers

These headers are used for audit IP logging.

PVE_ENDPOINTS=https://pve1.example.com:8006
